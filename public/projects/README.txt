Drop your project screenshots in this folder, e.g. task-manager.png,
then reference them in src/data.js like:

  image: '/projects/jadoo.png',
  image: '/projects/Gocart.png',
  image: '/projects/social-media.png',
  image: '/projects/cripson-bottle.png',

Recommended: 800x600px (4:3) or similar, JPG/PNG/WebP, under ~300KB each
for fast page loads.
